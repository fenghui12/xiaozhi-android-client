# v1.2.11：实时语音打断与新旧音频设备自动兼容

设备接入已验证的 Yundea 1076 麦克风/喇叭一体 USB 声卡后，可以在播报时直接插话：停止当前回答并继续听新问题，不必再次喊唤醒词。旧的摄像头麦克风＋主板喇叭继续使用原来的语音交互方式。

- 同一安装包自动识别两套音频硬件，拔插后自动切换模式，无需重启或手动选择。
- 未识别、缺少输入/输出或录放跨卡的设备组合保留标准语音模式，关闭自动打断。
- 一体声卡取消额外软件放大，减少残余回声误触发；打断时清除旧播报并保留插话句首。
- 合并此前已在联调包中的修复：首次运行申请麦克风/相机权限、录音异常后唤醒自恢复、连接失败后的退避重连及会话状态恢复、监督任务复核状态修正。
- 其他角色、素材、摄像头和提醒功能继续共用，覆盖升级保留现有数据。

验证：67 条单元测试、release 构建通过；真机新→旧→新热切换通过，旧设备唤醒/回答正常，新声卡插话成功且用户确认没有自打断。

打断仅启用于已验证的 Yundea 1076（USB VID/PID 4759:3931、实际录放同地址）。其他样机、高音量/远距离及提醒/监督播报中的打断尚未单独验收；监督链路和首次安装授权仍有未完成的现场验证。超声波联调不包含在本版。
